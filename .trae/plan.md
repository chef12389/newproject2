# 首页全面优化方案

## 现状诊断

当前首页分为三大板块：Hero 英雄区、四大核心模块区、更多门类浏览区。上一轮改版已奠定了较好的基础，但仍存在以下可优化空间：

### 问题清单

| 板块 | 问题 | 严重度 |
|------|------|--------|
| **Hero 区** | Spotlight 卡片与左侧文案视觉权重不平衡，右侧偏重；移动端 Spotlight 挤压严重 | 高 |
| **Hero 区** | 知识脉络流(flow)步骤间箭头太弱，视觉连接感不足 | 中 |
| **Hero 区** | 滚动提示(scroll hint)过于低调，几乎不可见 | 低 |
| **模块卡片区** | 四张卡片视觉完全对称，缺乏主次差异；第一张"营造华章"应作为主入口突出 | 高 |
| **模块卡片区** | 卡片缺少视觉锚点（无图片），纯文字信息密度偏低 | 高 |
| **模块卡片区** | 卡片 hover 效果与全局 aliveCardHover 一致，缺少卡片自身的微交互特色 | 中 |
| **更多门类区** | 列表项视觉过于朴素，与上方精心设计的模块卡片区形成落差 | 高 |
| **更多门类区** | 缺少"查看全部"等完整导航入口 | 中 |
| **全局** | Hero 与主内容区之间缺少过渡衔接，视觉割裂 | 中 |
| **全局** | 深色模式下模块卡片背景过于统一，四色区分度不足 | 中 |
| **全局** | 缺少页脚收束，页面底部突然结束 | 低 |

---

## 优化方案

### 一、Hero 英雄区优化

#### 1.1 Spotlight 卡片增强
- **内框装饰升级**：将静态内框改为带有微光流动效果的金色内框，使用 `@keyframes` 实现边框光效缓慢流动
- **增加案例数量提示**：在 Spotlight 标签旁显示案例总数，如"代表案例 · 12例"
- **悬停时显示更多内容**：hover 时 summary 文字从截断变为完整展示

#### 1.2 知识脉络流增强
- **箭头升级**：将 1px 细线箭头替换为带箭头符号的连接器（→），使用 SVG chevron 图标
- **步骤卡片增加悬停效果**：hover 时步骤卡片微微上浮并高亮边框
- **当前步骤指示**：为第一个步骤添加"推荐起点"的微标记

#### 1.3 滚动提示增强
- **增加竖线动画**：在文字旁增加一条从上到下缓慢流动的渐变竖线，暗示滚动方向
- **提高对比度**：将颜色从 `rgba(210, 195, 170, 0.4)` 提升至 `rgba(210, 195, 170, 0.6)`

#### 1.4 移动端适配
- **Spotlight 改为横向滑动卡片**：在移动端将 Spotlight 从网格布局改为全宽卡片，高度适当压缩
- **Flow 步骤横向滚动**：移动端 flow 区域支持横向滑动

---

### 二、四大核心模块区优化

#### 2.1 首卡突出（Bento 布局）
- **第一张卡片跨列显示**：在桌面端，"营造华章"卡片占据两列宽度，形成大卡+三小卡的 Bento 布局
- **首卡增加背景图**：大卡左侧/底部增加半透明建筑图片作为视觉锚点，叠加渐变遮罩确保文字可读
- **首卡标题放大**：大卡标题字号从 `1.6rem` 提升至 `2rem`

#### 2.2 卡片微交互增强
- **悬停时顶部色条扩展**：hover 时色条从 3px 扩展为 6px，并向下渐变扩散
- **图标旋转微动**：hover 时图标增加轻微旋转（5deg），而非仅缩放
- **底部行动线扩展**：hover 时"进入模块"文字下划线动画改为从左到右的墨迹扩散效果
- **序号水印变色**：hover 时序号从极淡色变为半透明主题色

#### 2.3 深色模式卡片差异化
- **每张卡片左侧增加 3px 宽的色条**（与顶部色条同色），在深色模式下提供更明确的色彩区分
- **深色模式卡片背景微调**：每张卡片的背景叠加极淡的主题色 tint，而非统一的深蓝灰

#### 2.4 卡片内容增强
- **增加"子模块数量"提示**：如"3 个专题 · 12 个案例"，放在描述文字下方
- **诗意副标题增加引号装饰**：如「栋宇千秋」，用中式引号包裹

---

### 三、更多门类浏览区优化

#### 3.1 列表项视觉升级
- **左侧色条加宽并增加圆角**：从 4px×32px 改为 5px×36px，圆角从 2px 改为 3px
- **增加序号标记**：每个条目左侧色条旁增加淡色序号（如 05、06...）
- **悬停时色条高度扩展**：hover 时色条从 36px 扩展为全高
- **增加右侧箭头动效**：hover 时箭头从隐藏状态滑入并变为主题色

#### 3.2 增加"查看全部"入口
- **在标题行右侧增加"查看全部 →"链接**，点击跳转到完整的建筑分类页面

#### 3.3 列表项分组
- **将 6 个条目分为两组**，每组 3 个，组间增加淡色分割线和组标题（如"宗教与纪念"、"园林与民居"）

---

### 四、全局优化

#### 4.1 Hero 与主内容区过渡
- **增加装饰性分割线**：在 Hero 底部与主内容区之间增加一条渐变装饰线，使用中式纹样（简化回纹或如意纹）的 SVG
- **或使用渐变过渡**：Hero 底部增加一个从深色到内容区背景色的 80px 渐变过渡带

#### 4.2 页脚收束
- **增加简洁的页脚区域**：包含站点名称、版权信息、以及一行核心导航链接
- **使用极简设计**：淡色文字 + 细分割线，不喧宾夺主

#### 4.3 动画性能优化
- **为所有 hover 动画增加 `will-change: transform`**（已有部分）
- **减少同时动画的元素数量**：flow 步骤的 pulse-dot 动画改为仅第一个步骤有
- **为 `prefers-reduced-motion` 添加回退**：所有动画在减少动效模式下禁用

---

## 实施步骤

1. **Hero 区优化**：修改 HomePage.tsx 中 Hero 部分的 JSX 结构和 index.css 中对应样式
2. **模块卡片区优化**：重构卡片布局为 Bento 风格，首卡跨列+背景图，修改 CSS Grid 和卡片样式
3. **更多门类区优化**：增强列表项视觉，增加"查看全部"入口
4. **全局优化**：添加过渡装饰、页脚、动画回退
5. **验证构建**：运行 `tsc --noEmit` 和 `vite build` 确保无错误
